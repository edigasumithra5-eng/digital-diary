# 📔 Digital Diary Using Python

## 📌 Project Description

The **Digital Diary** is a simple desktop application developed using **Python and Tkinter**.

It allows users to write, save, view, and delete personal diary entries using an easy-to-use graphical interface.

The project demonstrates Python concepts such as GUI programming, file handling, functions, loops, conditional statements, and exception handling.

## 🎯 Objectives

* Create a simple digital diary.
* Allow users to write daily entries.
* Save diary entries permanently.
* View previously saved entries.
* Delete unwanted entries.
* Provide a simple graphical user interface.

## 🛠 Technologies Used

* Python 3
* Tkinter
* File Handling
* Visual Studio Code

## ✨ Features

## 💻 Requirements

Install Python 3.x.

Check the Python version:

```bash
python --version
```

Tkinter is normally included with Python.

Test Tkinter using:

```bash
python -m tkinter
```

## ▶️ How to Run in VS Code

### Step 1: Open VS Code

Open Visual Studio Code.

### Step 2: Create Project Folder

Create a folder named:

```text
digital-diary-python
```

### Step 3: Create Python File

Create:

```text
digital_diary.py
```

### Step 4: Copy the Program

Copy the Python code from this repository into `digital_diary.py`.

### Step 5: Run the Program

Open the VS Code terminal and execute:

```bash
python digital_diary.py
```

## 📝 How to Use

1. Start the application.
2. Select or enter a date.
3. Write your diary entry.
4. Click **Save Entry**.
5. Use **View Entry** to read a saved entry.
6. Use **Delete Entry** to remove an entry.
7. Click **Clear** to clear the text area.

## 📊 Example

### Input

```text
Date:

using Python and Tkinter.
```
